# Front Office League

An NFL franchise-management simulator: run the organization (roster, salary cap, draft, coaching, development) and never call a play.

**Play:** https://wittcombs.github.io/front-office/

It installs as an app and works offline:
- **Computer (Chrome or Edge):** click the install icon at the right end of the address bar.
- **iPhone (Safari):** Share → Add to Home Screen.
- **Android (Chrome):** ⋮ menu → Install app.

When a new version is published, the app shows "A new version is ready" the next time it opens online. Tap **Update now**. Saves stay on your device.

This repository holds only the built game.
